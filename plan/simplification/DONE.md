## Deploy to Vercel (recommended)

The app needs an SSR/Node host because two route handlers run server-side
(`/api/eleven/signed-url`, `/letters/[id]/qr.png`). It is **not** a static export.

### 0. Pre-deploy (do this first)
- **Rotate `XI_API_KEY`.** The old key was committed in `backend/.env` and remains in git history
  even though the file is deleted. Generate a fresh ElevenLabs key and use that below.
- Ensure the ElevenLabs agent `NEXT_PUBLIC_AGENT_ID` already exists with
  `conversation_config_override` + auth enabled (it does — it's the live demo agent).

### 1. Push and import
```bash
git add -A          # stages the simplification (already staged; re-run if you also want plan/)
git commit -m "Simplify to a single Next.js app; remove backend + Supabase"
git push
```
In Vercel: **New Project** → import the repo → set **Root Directory = `frontend/`** (pnpm
auto-detected; build `pnpm build`, output auto).

### 2. Environment variables (set ALL four for Production *before* the first deploy)

| Variable | Value | Phase | Notes |
|---|---|---|---|
| `XI_API_KEY` | *(the rotated key)* | **runtime** | mark **Sensitive**; read only inside the signed-url handler |
| `NEXT_PUBLIC_AGENT_ID` | `agent_…` | **build-time** | inlined into the bundle |
| `NEXT_PUBLIC_XI_VOICE_ID_ENGLISH` | `YCMgeo2Dvws6xwm7kQNN` | **build-time** | |
| `NEXT_PUBLIC_XI_VOICE_ID_WELSH` | `73fZMjboCm1aBVyxTbBp` | **build-time** | |

> A `NEXT_PUBLIC_*` var is frozen into the bundle at build time — it must be present **before** the
> build, and changing it later requires a redeploy. `XI_API_KEY` is read at runtime only (the GET
> handler never runs at build), but Vercel's single env panel covers both phases, so just set all
> four. `lib/env.ts` validates these at module load and throws the build if a `NEXT_PUBLIC_*` is
> missing — so the four above are the *complete and exact* required set; no others.

### 3. Deploy & verify
```bash
vercel --prod         # or just let the git push trigger the build
```
Smoke the deployed URL: `/` (200), `/letters/maria-p2/preview` (QR loads from
`/letters/maria-p2/qr.png`), `/l/maria-p2` (summary renders), and start a voice chat
(`/api/eleven/signed-url` → 200). No database, no migrations, no second process.

### Alternatives (if not Vercel)
Netlify (zero-config Next 16 via its OpenNext adapter — effectively a tie) or Cloudflare Workers via
`@opennextjs/cloudflare` (needs `nodejs_compat`; the build/runtime env split is a manual footgun).
See `02-research/frontend-hosting.md`.
