# Frontend Exploration — Marginalia (`frontend/`)

Scope: full map of `frontend/` (App Router routes, components, lib, scripts, public assets) with a
runtime-usage verdict for every file, and a complete enumeration of which backend endpoints the
frontend actually calls vs. which it never touches. Goal context: simplify toward a cold deploy by
eliminating the FastAPI backend (inlining the two static demo letters), leaving a Next.js app whose
only genuine server runtime is `/api/eleven/signed-url`.

All paths are absolute. Line references are to the file as read on 2026-06-26.

---

## TL;DR — the simplification-critical facts

- **Frontend calls only TWO backend (FastAPI) endpoints at runtime:** `GET /letters/{id}` and
  `GET /letters/{id}/qr.png`. Everything else the backend exposes is never called by the frontend.
- **The one genuine server runtime to keep is** `/Users/haidertoha/Code/i.ai_hackathon/frontend/app/api/eleven/signed-url/route.ts` — it mints an ElevenLabs signed WebSocket URL using the server-only `XI_API_KEY`. It does **not** touch the FastAPI backend.
- **Supabase Auth is NOT wired in.** Zero imports of `@supabase/supabase-js` (or any supabase client) anywhere in `frontend/`. The `NEXT_PUBLIC_SUPABASE_*` vars are *validated* in `lib/env.ts` but *consumed nowhere*. Same for `NEXT_PUBLIC_ONE_LOGIN_URL`.
- **`getHealth()` (and the `Health` type) in `lib/api.ts` is dead** — defined, never called.
- **`/l/[id]` reads `../backend/prompts/letter_explainer.txt` from disk at server start** (`readFileSync`). Removing the backend dir breaks this unless the prompt is inlined/relocated.
- **Two served vendor assets are git-ignored AND not regenerated by the build script** (`public/vendor/govuk-frontend.scoped.css`, `public/vendor/govuk-logotype.svg`). A fresh clone + build will be missing them → broken GOV.UK styling/crown. This is the single biggest cold-deploy landmine.
- All demo letter data needed for inlining is the two rows in `supabase/migrations/20260625090200_seed_demo_letters.sql` (quoted in full below).

## Backend endpoints — called vs. not called

The backend mounts five routers (`/Users/haidertoha/Code/i.ai_hackathon/backend/app/main.py:51-55`):
`health`, `items`, `letters`, `govuk`, `scan_events`.

## (3) AMBIGUOUS / needs-decision

1. **Untracked, un-regenerated vendor assets (cold-deploy landmine).**
   `frontend/.gitignore` (per `git check`) ignores `frontend/public/vendor/` with the comment
   "Vendored ... by scripts/copy-govuk-assets.ts (predev/prebuild)". But the copy script **only**
   regenerates `govuk-frontend.min.css`. There is **no generator** for
   `govuk-frontend.scoped.css` or `govuk-logotype.svg` anywhere in the repo (grep for `scoped` and
   `logotype` across scripts/Makefile/ts/js → none). `git ls-files frontend/public/vendor/` returns
   **nothing** → both files exist only on this machine. **A fresh clone + `pnpm build` will be
   missing the scoped GDS CSS and the crown SVG**, breaking the `/actions/*` pages and the in-chat
   GOV.UK overlay styling. Decision needed: commit these two files, or add a real generation step
   (scope the CSS + copy the logotype) to `copy-govuk-assets.ts`.

2. **The `readFileSync` of `../backend/prompts/letter_explainer.txt`** (`app/(phone)/l/[id]/page.tsx:16-19`).
   To drop the backend directory, the 18-line system prompt must be inlined into the frontend (or
   moved to a frontend asset). Full text captured below for the inlining phase.

3. **The QR image dependency** (`preview/page.tsx:359`, `GET /letters/{id}/qr.png`).
   Eliminating FastAPI removes the QR generator. Options: inline a pre-rendered static PNG per
   letter, add a tiny Next route handler that generates the QR, or generate client-side. The QR
   payload is the absolute URL of `/l/{id}` (built request-side in the backend), so the replacement
   must encode the deployed origin + `/l/{id}`.

4. **Unused env vars (Supabase / One Login).** Listed as unused in bucket 2; the *decision* is
   whether to delete them from the `lib/env.ts` schema (recommended for cold deploy, since the
   required Supabase vars otherwise hard-fail `schema.parse` at boot) or keep as placeholders.

5. **`frontend/scripts/export-letter.ts`** — manual Playwright tooling (`pnpm tsx scripts/export-letter.ts <id>`),
   **not** referenced by any `package.json` script, so never part of dev/build/runtime. It screenshots
   `/letters/{id}/preview` into `out/{id}.pdf` + `.png`. Dev-only authoring tool. Decision: keep as
   tooling or drop; it has no runtime impact.

6. **`frontend/out/` artifacts** (`out/maria-p2.pdf`, `out/maria-p2.png`). Git-ignored
   (`frontend/.gitignore: frontend/out/`). These are the *printed* letters scanned on stage — demo
   props, not app runtime. Output of `export-letter.ts`. Not part of the deployable app.

7. **`wordmark.tsx` / `not-found.tsx`** — only mutually referenced; keep-or-drop depends on whether a
   styled 404 is wanted in the slimmed build.
